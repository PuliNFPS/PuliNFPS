## 🧑‍💻 Sobre mim

- 🎓 Estudante de **Engenharia da Computação** no **SENAI CIMATEC**
- 💻 Minha stack principal é **C, Java e Python**
- 🖱️ Criador do **[OmniGear](https://github.com/PuliNFPS/OmniGear)**, um app web para configurar mouses e teclados gamers de várias marcas num só lugar, sem instalar um monte de programa pesado
- ⛏️ Desenvolvo o **[BAH Launcher](https://github.com/PuliNFPS/bah-launcher-release)** e mods para os modpacks do **[Bahcraft](https://github.com/Bahcraft)**
- 🤝 Contribuí com o **[Synaptik](https://github.com/luneto10/Synaptik)**, ferramenta para modelar bancos de dados visualmente e gerar SQL, Prisma e C# EF Core
- 💬 Pode me chamar para falar de **C, Java, Python e mods de Minecraft**
